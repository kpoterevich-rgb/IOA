# Контрольный список безопасности OlympIA

## Обязательное до публичного запуска
- [ ] Удалить клиентский пароль администратора и заменить его серверной аутентификацией.
- [ ] Включить Supabase Auth и Row Level Security для всех таблиц.
- [ ] Проверять права администратора только на сервере.
- [ ] Считать баллы на сервере; не отдавать правильные ответы клиенту во время прохождения.
- [ ] Не хранить секреты AI-провайдера в HTML, репозитории или браузере.
- [ ] Ограничить частоту запросов к AI и размер сообщений; добавить лимит расходов.
- [ ] Сделать общий серверный рейтинг, отделённый по предмету и классу.
- [ ] Проверить, что пользователь не может редактировать чужие профили, олимпиады или результаты.
- [ ] Добавить политику конфиденциальности и контакт для запросов на удаление данных.
- [ ] Решить, действительно ли email нужен. Если нет — не собирать его.
- [ ] Указать, какие данные собираются, зачем и как долго хранятся.
- [ ] Проверить безопасность HTML-редактора: не вставлять пользовательский HTML через `innerHTML` без очистки.
- [ ] Проверить доступность с клавиатуры, контрастность, локализацию, ошибки сети и пустые состояния.
- [ ] Проверить восстановление после перезагрузки, таймер и серверную защиту от повторной отправки.
- [ ] Провести тестирование на телефонах и компьютерах и сделать резервную копию базы.

## Тестовые сценарии
1. Участник A не видит профиль или email участника B.
2. Участник не может создать или изменить роль администратора.
3. Участник не может читать таблицу ключей правильных ответов.
4. Изменение олимпиад в админке появляется у других пользователей только после сохранения на сервер.
5. Результат после завершения записывается один раз и не может быть изменён участником.
6. Таймер заканчивается на сервере, а не только в браузере.
7. При сбое сети сайт сообщает об ошибке и не заявляет, что результат сохранён.
8. Рейтинг одинаков на разных устройствах.
